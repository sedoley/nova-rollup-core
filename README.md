# nova-rollup-core

Production-grade OP Stack L2 rollup core.

A high-performance, Ethereum-compatible Layer 2 rollup built on the OP Stack with native Base integration.

## Features
- Full EVM compatibility
- Optimized sequencer batching and state transitions
- Danksharding-ready blob support (EIP-4844)
- SNARK proof verification pipeline
- L1 ↔ L2 bridge with secure deposit relay
- Gas Price Oracle integration
- Comprehensive test coverage

## Tech Stack
- **Core**: Python + Rust components
- **Contracts**: Solidity (OP Stack compatible)
- **Infrastructure**: Docker + Kubernetes manifests
- **Testing**: pytest + integration suite
- **CI/CD**: GitHub Actions
